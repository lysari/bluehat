# Project Rules

## Tech Stack
- Language & Framework: Swift 6 (SwiftUI, macOS 26+ `MenuBarExtra`)
- Package Manager: Swift Package Manager, run through Devbox with the Xcode toolchain

## Architecture & Directory Map

```text
Sources/
├── BluehatCore/                 # library: rule model, signed feed, scan engine
│   ├── Models/                  # Rule, Rulebook, Finding, IgnoredFinding, ScanSchedule, ScanRecord
│   └── Services/                # RuleFeed (download + verify), Scanner (checks), ScanHistory (saved scans)
├── Bluehat/                     # menu bar app
│   ├── Views/                   # one SwiftUI view per file; <Type>+Presentation.swift for display text of core types
│   ├── Stores/                  # @Observable state: ScanStore, SettingsStore
│   ├── Utilities/               # shared view helpers with doc comments: card(), counted()
│   └── Theme/                   # design tokens: Palette, Metrics, Typography, Motion
└── bluehat-sign/                # CLI that validates and signs rules.json
Tests/BluehatCoreTests/          # mirrors Sources/BluehatCore paths
scripts/                         # bundle.sh builds Bluehat.app, install.sh copies it to /Applications, make-icon.swift draws the app icon
assets/                          # AppIcon.icns, generated by `devbox run icon`
rules/                           # separate git repo pushed to lysari/bluehat-rules
```

- New check types belong in: `Sources/BluehatCore/Models/Rule.swift` (`CheckKind` + validation), `Sources/BluehatCore/Services/Scanner.swift`, and `Sources/Bluehat/Views/CheckKind+Presentation.swift` (title, symbol, fix hint). Append new cases at the end of `CheckKind`.
- Rules never carry commands or code; every check is implemented in `Scanner`.

## Naming Conventions
- Files: PascalCase, named after the main type
- Types: PascalCase; functions and values: camelCase
- Domain terms: `rule`, `rulebook`, `finding`, `check`; never `signature` for a rule (signature means the Ed25519 signature)

## Core Shared Helpers (Do Not Duplicate)
- Rule download and verification: `RuleFeed`
- Running system tools and matching text: `Scanner.runTool`, `Scanner.regexes`, `Scanner.matches`

## UI & Styling Conventions
- Framework: SwiftUI
- Tokens & Theme: `Sources/Bluehat/Theme/` (`Palette` colors, `Metrics` spacing and sizes, `Typography` fonts, `Motion` animations)
- Icons: SF Symbols
